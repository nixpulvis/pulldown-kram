Struct Extensions 

Source 
pub struct Extensions(/* private fields */);
Expand description

The parts of kramdown’s syntax that go beyond CommonMark, each of which can be turned off.

With every extension on, as in Extensions::all(), documents are parsed the way kramdown parses them. Some extensions are parsed by pulldown-cmark itself, and say which of its options they turn on. See Options for how those interact with Options::cmark.

The flags come in groups:

  • Syntax pulldown-cmark also reads, from tables to math, which turn on its option for it.
  • Attribute lists, and the ids and classes that come from them.
  • kramdown’s own block and span syntax.
  • Where kramdown reads CommonMark’s syntax differently.

ENABLE_TABLES_OF_CONTENTS makes Document::events collect every event before returning the first, since a table can link to headings after it. Extensions::streamable() leaves it out, so events are returned a block at a time. Any other extension can be turned off by removing it from Extensions::all():

use pulldown_kram::{Document, Extensions, pulldown_cmark::Event};

// Everything except typography, so quotes stay straight.
let extensions = Extensions::all() - Extensions::ENABLE_TYPOGRAPHY;
let document = Document::new("\"a\"\n", extensions);
let text: Vec<_> = document
    .events()
    .filter_map(|(event, _)| match event {
        Event::Text(text) => Some(text),
        _ => None,
    })
    .collect();
assert_eq!(text, ["\"a\"".into()]);

Source

pub const ENABLE_TABLES_OF_CONTENTS: Self

Lists marked {:toc} turned into tables of contents, linking to every heading that has an id and doesn’t have the class no_toc. The marker is a block attribute list, so this needs ENABLE_BLOCK_ATTRIBUTES.

Every event is collected before the first is returned, so tables can link to headings after them. Each table lists every heading, so output could grow with the square of the document’s size. To bound it, tables of contents produce at most 100,000 events or as many as the document has, whichever is larger; marked lists past that limit are left as written.

pub const ENABLE_END_OF_BLOCK_MARKERS: Self

The end-of-block marker, a line with only ^, closing the blocks open at that point, like a list or a code block. It produces no events.

Source

pub const ENABLE_BACKSLASH_LINE_BREAKS: Self

Hard line breaks with two backslashes at the end of a line, as well as with two spaces.

Source

pub const ENABLE_TABLES_WITHOUT_HEADERS: Self

Tables without a header row, like a lone | a | b | line, and a | in code in a table cell kept in that cell instead of starting a new one. Also accepts a separator line with fewer cells than the header, or + between its cells. pulldown-cmark parses the tables, so this needs ENABLE_TABLES.

pub const ENABLE_ABBREVIATIONS: Self

Abbreviations, *[HTML]: HyperText Markup Language. Each use in the text becomes an <abbr> with its title.

pub const ENABLE_MARKDOWN_ATTRIBUTE: Self

Markdown inside HTML elements marked markdown="1". The attribute is removed from the HTML.

Source

pub const ENABLE_COMMENTS: Self

kramdown’s comment extension, {::comment}…{:/}, as a block or span, emitted as an HTML comment.

Source

pub const ENABLE_NOMARKDOWN: Self

kramdown’s nomarkdown extension, {::nomarkdown}…{:/}, as a block or span, emitted as raw HTML unless its type names another of kramdown’s converters, like latex.

Source

pub const ENABLE_HTML_BLOCK_ENDS: Self

HTML blocks that end at the end tag of the element that opened them, as in kramdown, with any text after it parsed as Markdown. CommonMark’s HTML blocks run to the next blank line. A blank line before the end tag still ends the block, as in CommonMark.

Source

pub const ENABLE_SPAN_TAG_PARAGRAPHS: Self

A line with only a span-level tag, like <img>, starts a paragraph together with the text on the next line, instead of an HTML block. Followed by a blank line, it’s still an HTML block, where kramdown makes it a paragraph.

Source

pub const ENABLE_RAW_HTML_SPANS: Self

The text of the HTML spans kramdown leaves raw, like <kbd>, <code> and <var>, passed through unchanged, without Markdown or typography applied inside them.

Source

pub const ENABLE_LIST_ITEM_PARAGRAPHS: Self

Tight and loose list items decided per item, as kramdown does, rather than per list: an item’s first paragraph is only wrapped in a paragraph if a blank line follows it in the item.

Source

pub const ENABLE_MIXED_LIST_MARKERS: Self

One list for items marked with any mix of *, + and -. CommonMark starts a new list whenever the marker changes.

Source

pub const ENABLE_KRAMDOWN_ESCAPES: Self

Backslash escapes for only the characters kramdown escapes. A backslash before any other character, like \&, is kept, where CommonMark escapes all ASCII punctuation.

pub const fn streamable() -> Self

Every extension except ENABLE_TABLES_OF_CONTENTS, so Document::events returns events a block at a time instead of collecting them all first. Lists marked {:toc} stay as written.

use pulldown_kram::{Document, Extensions};

let document = Document::new("* x\n{:toc}\n", Extensions::streamable());
assert_eq!(document.events().count(), 5);
